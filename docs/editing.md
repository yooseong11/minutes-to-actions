# 추출 후 안건 편집

2026-09-14 구현. 기존 더미 데이터 (01번) 버튼으로 API 호출 없이 확인할 수 있습니다.

- 각 안건의 **수정**: 내용, 분류(결정/할 일/미결), 담당자, 기한을 수정합니다.
- 담당자: 참석자 버튼으로 선택하거나 이름과 소속을 직접 입력합니다. 비워둘 수 있습니다.
- **수정** 화면의 담당자 지우기 / 기한 지우기: 해당 값만 비웁니다. 수정 적용 전에는 반영되지 않고 원문 근거는 유지합니다.
- 카드의 붉은색 **삭제**: 안건을 목록에서 제거합니다. **마지막 변경 되돌리기**로 수정·삭제·추가를 역순으로 취소합니다.
- 각 분류의 **+ 안건 추가**: 내용은 필수이며 담당자·기한은 선택 사항입니다.
- 분류를 바꾸면 해당 섹션으로 이동합니다.
- 기한 계산 기준일의 **다시 계산**: AI를 재호출하지 않습니다. 직접 지정하거나 삭제한 기한은 보존합니다.

## 데이터 처리

`lib/edit.ts`가 편집을 처리하며 최초 추출값은 `original`, 변경 필드는 `editedFields`에 남깁니다.
직접 추가한 안건은 `userCreated`로 구분하고 원문 인용을 만들어 넣지 않습니다.
담당자 수정은 담당자 관련 검토 사유만 바꾸며 조건부·선행조건 등 다른 경고는 유지합니다.
내용 수정만으로 기존 경고가 자동 해제되지는 않습니다. 금액 단위 등 별도 확인 절차는 후속 범위입니다.

수정값은 현재 화면 메모리에만 있습니다. 새로고침, 새 추출, 더미 데이터 재불러오기로 초기화됩니다.
서버 저장·내보내기는 아직 구현하지 않았습니다. 내보내기는 현재 편집 결과를 사용해야 합니다.

## 검증

- 기존 테스트 59개 + 편집 데이터 무결성 테스트 5개 통과.
- 더미 데이터로 브라우저에서 담당자 선택/직접 입력, 내용·기한 수정, 필드 삭제,
  안건 추가·삭제·복구, 분류 이동, 빈 내용 거부, 기준일 변경 후 수동 기한 보존 확인.
- 빌드 통과. 린트는 기존 `lib/date.ts` 정규식 경고 3건이 남아 있습니다.
