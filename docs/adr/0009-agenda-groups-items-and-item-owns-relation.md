# 0009. 안건 아래 발화 항목을 두고, 소속은 항목만 갖는다

## 결정
원시 스키마는 `agendas[].items[]`, 후처리는 평면 `items` + `agendaId`로 두고, 안건은 항목 ID 목록을 갖지 않는다.

## 이유
사람이 읽는 단위는 안건이고 인용 검증·CSV 단위는 발화 항목이며, 소속을 한쪽에만 두면 항목을 지워도 관계가 어긋나지 않는다.

## 버린 대안
- 항목 단위 자체를 안건으로 변경: 환각 탐지(0005)와 CSV 내보내기를 다시 만들어야 한다.
- 안건에도 항목 ID 목록 보유: 항목을 지우면 한쪽이 어긋나 화면이 없는 항목을 그린다.
